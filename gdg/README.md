# GDG CTF Summary

This folder contains my GDG Cyber Recruitments challenge writeups.

## Brief Insights

- Follow a layered approach: recon first, then deeper analysis.
- Git and binary challenges reward careful static inspection.
- Web challenges often chain small weaknesses into major impact.
- Automation saves time when handling repetitive data (QRs/logs/decoding).
- Red herrings are common; validate assumptions at each step.
